## О проекте

**Rentcalc** — веб-приложение для просмотра информации о квартирах, услугах, счётчиках и платежах в сфере ЖКХ.

Frontend-часть реализована на **Vue.js 3** и взаимодействует с backend-API на **Laravel** (Laravel Sanctum) по протоколу HTTP.

## Технологии

- Vue.js 3
- Vue Router
- Pinia (управление состоянием)
- Axios (HTTP-запросы)
- Vite (сборка)
- ESLint + Prettier (качество кода)
